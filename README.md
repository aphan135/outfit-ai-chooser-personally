# 🎲 Outfit Roulette

An interactive web application designed to eliminate daily decision fatigue by generating styled outfits based on custom vibes, weather conditions, or occasion prompts. Users can lock individual items, reroll specific slots, save tailored outfits, and view item details.

![Outfit Roulette Screenshot](https://raw.githubusercontent.com/aphan135/outfit-ai-chooser-personally/main/images/preview.png) *(Optional: Replace link with an image URL of your app)*

---

## ✨ Features

- **Vibe-Based Outfit Generation:** Smart keyword matching for styles like `casual`, `gym`, `rainy`, `formal`, `wedding fit`, and `winter`.
- **Slot Locking & Rerolling:** Lock items you like (`Hat`, `Top`, `Bottom`, `Shoes`) while rerolling individual unlocked slots or spinning the full outfit.
- **Dynamic Receipt & Cost Breakdown:** Real-time itemized pricing breakdown with total cost calculations.
- **Saved Wardrobe & Outfit Details:** Save generated outfits locally and pop open detailed item breakdowns (price, store, descriptions, and color swatches).
- **Responsive & Animated UI:** Custom modular CSS layout with micro-animations and slide-out wardrobe drawer.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Custom CSS Grid & Flexbox, SVG Vector Art, Google Fonts (*Bricolage Grotesque*, *Work Sans*, *Space Mono*)
- **Storage:** Browser `localStorage` for persistent wardrobe management
- **Server:** Python `http.server` (Local Development)
